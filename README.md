# Modern Dynamic Portfolio with Admin Dashboard

A fullstack developer portfolio powered by **React (Vite)**, **Express.js**, **MongoDB Atlas**, **Cloudinary CDN**, and **Firebase Auth**.

## ?? Architecture & Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide Icons, React Router
- **Backend**: Node.js & Express with Mongoose
- **Database**: MongoDB Atlas (Live Cloud Cluster)
- **Media Hosting**: Cloudinary (Unsigned upload preset for free image hosting)
- **Authentication**: Firebase Auth (Google Sign-In & Email/Password)
- **Deployment**: Vercel (Unified Frontend + Serverless API)

1. Import this repository in [Vercel](https://vercel.com/).
2. Add the environment variables listed in \.env.example\.
3. Click **Deploy**!
